# Operator 정본 문서에서 등급 의미 찾기

이 참조는 **등급 의미의 정본을 어디서 읽을지**만 정의한다. 모델 배정은 `00-오케스트레이션-작업지침.md`가 소유한다.

## 검색 순서

현재 작업의 `REPOSITORY_ROOT`를 기준으로 다음 순서로 읽는다.

1. `docs/운영_오퍼레이터_등급_정의_v1.0.md`를 필수 정본으로 읽는다.
2. `review/handovers`의 최신 관련 `*HANDOFF*.md`, `*handoff*.md`를 작업 맥락으로 읽는다.
3. `review/packets`의 오퍼레이터·assignment 문서와 `review/plans`의 해당 슬라이스 계획을 보조 근거로 읽는다.

각 후보 문서의 대상 저장소가 `C:\sswcenter\3.0`인지 먼저 확인한다. `C:\sswcenter\2.2`를 대상 저장소로 선언하는 과거 handoff/report는 역사 기록으로 분류하고 읽거나 실행 근거로 사용하지 않는다. 과거 문서에 적힌 2.2 경로를 열거나 명령으로 재사용하지 않는다.

정본 파일이 없으면 `review` 문서나 래퍼 README에서 의미를 복구하지 말고 `BLOCKED`로 보고한다. 현재 슬라이스와 무관한 과거 Wave 문서나 외부 저장소 문서를 등급 의미의 근거로 사용하지 않는다.

## 추출 규칙

- 정본의 `등급` 열 1~5와 `의미·대표 범위`만 추출한다.
- 테스트 등급과 검수 등급을 분리한다.
- 모델, effort, fast, sandbox, network는 이 문서에서 추출하지 않는다. `00-오케스트레이션-작업지침.md`의 현재 배정을 사용한다.
- handoff가 정본과 다른 등급 의미를 담고 있으면 handoff를 정정 대상으로 보고하고 정본 문서의 의미를 사용한다.
- 정본 문서의 의미가 충돌하면 합의된 것으로 추측하지 말고 `BLOCKED`로 보고해 사용자 결정을 받는다.

## 현재 3.0 저장소의 정본

- `C:\sswcenter\3.0\docs\운영_오퍼레이터_등급_정의_v1.0.md`

이 스킬에서는 `C:\sswcenter\3.0` 밖의 등급 문서를 읽지 않는다. 2.2 문서나 Temp에 남은 제안 문서는 정본으로 승격하지 않는다. 정본 파일이 없거나 승인 버전이 불명확하면 `README.md`나 handoff의 모델 표로 대체하지 말고 `BLOCKED`로 보고한다.
