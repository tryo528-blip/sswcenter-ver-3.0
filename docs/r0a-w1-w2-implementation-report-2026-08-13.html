정리한 W1 계약

직원건강검진의 공개 입력·표시는 검진일만 두고, DB 내부에는 같은 직원 재직행을 가리키는 선택 연결만 둡니다. 분기상담은 완료 토글뿐이며 교육 seed는 정확히 8개입니다.
수급자·보호자수급자는 휴대전화만 필수입니다. 보호자는 고정 슬롯 1·2에 최대 2명이며 5개 필드는 모두 선택값입니다. 선택된 보호자 삭제 시 납부자는 수급자 본인으로 복귀합니다.
폐기 원장대표보호자·별도 납부자·서명자·인정전환 API/화면을 제거했습니다. 과거 테이블은 전진 migration에서 안전하게 교정합니다.
인정·혜택등급을 인정기간 값으로 통합했고, 수급자 생성 시 GENERAL을 자동 생성합니다. start_text는 계산에 쓰지 않는 빈 표시 텍스트입니다.
