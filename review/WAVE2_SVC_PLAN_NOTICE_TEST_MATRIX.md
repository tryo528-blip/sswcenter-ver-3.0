## 4. 명시적 부재 검사

- 인정 전환 preview/apply API·service·DB function.
- 작성마감일 D-100 카드 또는 내부 업무.
- 카드 진행률·퍼센트·`WAITING`·`EXEMPT`·재개방.
- 공식 카드와 개인 할 일 합침 API·브라우저 union.
- 별도 등급기간 원장 참조.
- 혜택 표시용 시작텍스트의 날짜 parse·비교·마감 계산.
- Wave 3 실제근무 원장이 없는 `직원교체상담` 자동생성.
- 형님 승인 전 `신규직원업무` 자동생성.

## 5. 실행 순서

1. 정본과 이 매트릭스의 정적 일치·금지토큰 검사를 먼저 실행한다.
2. 날짜·우선순위 `SEM`을 RED로 고정한다.
3. `0020+` migration과 실제 PostgreSQL `PG`를 GREEN으로 만든다.
4. API·OpenAPI·생성 TypeScript를 동기화한다.
5. 공식 카드 엔진 연결 뒤 중복·우선순위·권한을 실제 2-connection으로 검증한다.
6. 같은 후보에서 backup/restore와 독립 read-only 검수를 수행한다.
