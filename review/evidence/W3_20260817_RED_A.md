# W3 RED-A — 계획정정 proposal 순수함수

> 범위: `propose_plan_adjustment(...)` proposal-only 정책

## RED

테스트를 먼저 추가하고 다음 명령을 실행했다.

```text
env TMPDIR=/tmp TMP=/tmp TEMP=/tmp .venv/bin/python -m pytest -q -s \
  tests/test_w3_rfid_plan_adjustment.py
```

수집 단계에서 예상한 경계가 확인됐다.

```text
ModuleNotFoundError: No module named 'app.domains.w3'
1 error during collection
```

그보다 앞선 첫 실행은 Windows에서 유입된 임시경로 때문에 pytest capture가
`FileNotFoundError`로 끝났다. 이는 제품 RED로 계산하지 않고 Linux `/tmp`와 `-s`를
명시해 위 실제 missing-module RED를 분리했다.
