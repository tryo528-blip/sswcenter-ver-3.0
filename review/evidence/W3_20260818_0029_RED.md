## 1차 독립검수와 교정

Grok READ-ONLY 1차 검수에서 P0는 없었고 다음 승인범위 finding을 확인해 교정했다.

1. SQLAlchemy `IntegrityError.code` truthy 분기로 500이 새는 문제
2. supplement/plan idempotency 조회가 resource lock보다 앞선 문제
3. RFID manual link가 source service day/month를 확인하지 않던 문제
4. dataful `0029→0028→0029` 뒤 ACTIVE snapshot과 비어 있는 apply-control
5. 일부 409에 entity/current version/latest workspace가 없던 문제
6. supplement transition/plan rule의 `ValueError`가 500이 되던 문제
7. APPLY가 저장된 typed link와 확정월을 다시 검증하지 않던 문제
8. decision 응답을 1,000개에서 잘라 unresolved row를 숨길 수 있던 문제

`APPLIED A→B→A` 재활성 제안은 승인된 단방향 상태기계와 exact HTTP surface에
rollback/reactivate command가 없으므로 이번 finding으로 채택하지 않았다.
